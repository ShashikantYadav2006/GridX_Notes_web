CSS Basics

Important CSS concepts you should know.

01

CSS Syntax

CSS uses a selector followed by properties and values.

selector { property: value; }
02

Selectors

Selectors are used to target HTML elements.

/* Element */ p { color: blue; } /* Class */ .card { color: white; } /* ID */ #header { color: red; }
03

Colors

CSS supports named colors, HEX, RGB, RGBA and HSL.

color: red; color: #38bdf8; color: rgb(56,189,248); color: rgba(56,189,248,.5);
04

Background

Background properties control the background of an element.

background-color: #0f172a; background-image: url("image.jpg"); background-size: cover; background-position: center;
05

Fonts

CSS controls font family, size, weight and style.

font-family: Arial; font-size: 20px; font-weight: bold; font-style: italic;
06

Text

Text properties control alignment, spacing and decoration.

text-align: center; text-decoration: none; text-transform: uppercase; line-height: 1.7; letter-spacing: 2px;

CSS Box Model

Every HTML element behaves like a box.

07

Margin & Padding

Margin creates space outside an element. Padding creates space inside an element.

.box { margin: 20px; padding: 30px; }
08

Border

Borders appear around an element.

border: 2px solid blue; border-radius: 20px;
09

Width & Height

Control the size of an element.

width: 300px; height: 200px; max-width: 100%; min-height: 300px;
10

Box Sizing

Makes width and height calculations easier.

* { box-sizing: border-box; }
11

Border Radius

Creates rounded corners.

border-radius: 20px; border-radius: 50%;
12

Box Shadow

Adds depth and glow to elements.

box-shadow: 0 10px 30px rgba(0,0,0,.4);

CSS Layout

Learn how elements are positioned and arranged.

13

Display

Controls how an element is displayed.

display: block; display: inline; display: inline-block; display: flex; display: grid; display: none;
14

Position

Position elements using different positioning systems.

position: static; position: relative; position: absolute; position: fixed; position: sticky;
15

Z-Index

Controls which element appears on top.

position: relative; z-index: 100;
16

Flexbox

Flexbox is used for one-dimensional layouts using rows or columns.

.container { display: flex; justify-content: center; align-items: center; gap: 20px; }

CSS Effects

Make your website visually attractive.

19

Transform

Transform moves, rotates and scales elements.

transform: translateY(-10px); transform: scale(1.1); transform: rotate(20deg);
A
B
20

Transition

Transition makes property changes smooth.

.box { transition: 0.4s; } .box:hover { transform: scale(1.1); }
21

Gradients

Gradients create smooth color transitions.

background: linear-gradient( 135deg, blue, purple );
22

Box Shadow

Shadows add depth and glowing effects.

Glowing Card
23

Pseudo Classes

Pseudo classes style special states of an element.

:hover :active :focus :first-child :last-child :nth-child()
24

Pseudo Elements

Pseudo elements style specific parts of an element.

::before ::after ::first-letter ::first-line ::selection

CSS Animations

Learn how CSS animations work.

25

@keyframes

@keyframes defines the steps of a CSS animation.

@keyframes move { from { transform: translateX(0); } to { transform: translateX(200px); } } .box { animation: move 2s infinite; }
26

Animation Properties

Important properties used with animations.

animation-name animation-duration animation-delay animation-iteration-count animation-direction animation-timing-function animation-fill-mode
27

Infinite Animation

The animation can repeat continuously.

animation: float 3s infinite;
28

Hover Animation

Combine :hover with transition and transform for interactive effects.

.card { transition: .4s; } .card:hover { transform: translateY(-10px); }

Responsive CSS

Make websites work on mobile, tablet and desktop.

29

Media Query

Media queries apply different CSS depending on screen size.

@media (max-width: 600px) { .container { grid-template-columns: 1fr; } }
Resize the browser window 📱
30

Responsive Units

Useful responsive units include:

% vw vh rem em fr clamp()
31

clamp()

clamp creates flexible values.

font-size: clamp( 30px, 6vw, 80px );

CSS Variables

Store reusable values inside CSS variables.

32

Custom Properties

CSS variables make your stylesheet easier to maintain.

:root { --main-color: #38bdf8; --dark: #0f172a; } button { background: var(--main-color); }
33

calc()

Calculate CSS values dynamically.

width: calc( 100% - 40px );
34

overflow

Controls content that goes outside its container.

overflow: hidden; overflow: auto; overflow-x: scroll;

CSS Quick Revision

Important properties at one place.

/* Colors */ color: white; background: #0f172a; /* Text */ font-size: 20px; font-weight: bold; text-align: center; /* Box */ width: 300px; height: 200px; margin: 20px; padding: 20px; border: 1px solid white; border-radius: 20px; /* Flexbox */ display: flex; justify-content: center; align-items: center; /* Grid */ display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; /* Position */ position: relative; position: absolute; top: 0; left: 0; /* Effects */ box-shadow: 0 10px 30px black; transform: scale(1.1); transition: .4s; /* Animation */ animation: float 3s infinite; /* Responsive */ @media (max-width: 600px) { .box { width: 100%; } }
