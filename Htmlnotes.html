HTML Basics

HTML is the foundation of every web page.

What is HTML?

HTML stands for HyperText Markup Language .

  • HTML creates the structure of a webpage.
  • HTML uses elements and tags.
  • HTML is not a programming language.
  • CSS is used for styling.
  • JavaScript is used for behavior and interactivity.

HTML Element

An HTML element normally contains an opening tag, content and a closing tag.

<p>Hello World</p>
  • <p> = opening tag
  • Hello World = content
  • </p> = closing tag

Basic HTML Document

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0" > <title>My Website</title> </head> <body> <h1>Hello World</h1> <p>Welcome to my website.</p> </body> </html>

HTML Structure

Understand how an HTML document is organized.

<!DOCTYPE html>
<html>
<head>
Metadata / Title / CSS
<body>
Visible Website Content

<head>

The head contains information about the webpage that normally isn't displayed directly.

  • title
  • meta information
  • CSS links
  • favicon
  • SEO information

<body>

The body contains the content visible to website visitors.

  • headings
  • paragraphs
  • images
  • buttons
  • forms
  • sections

Text Formatting

HTML provides several text-related elements.

Headings

HTML provides six heading levels.

<h1>Main Heading</h1> <h2>Section Heading</h2> <h3>Sub Heading</h3> <h4>Heading 4</h4> <h5>Heading 5</h5> <h6>Heading 6</h6>
Tip: Normally use one main <h1> for the page's primary heading and organize subsequent sections logically.

Text Formatting

<strong>Important</strong> <em>Emphasized text</em> <mark>Highlighted</mark> <small>Small text</small> <del>Deleted text</del> <ins>Inserted text</ins> <sub>Subscript</sub> <sup>Superscript</sup>

Links & Images

Connect pages and display media.

Hyperlinks

The anchor tag is used to create links.

<a href="about.html"> About Us </a> <a href="https://example.com"> Visit Website </a> <a href="#contact"> Contact Section </a>

Images

<img src="photo.jpg" alt="A beautiful landscape" width="500" >

The alt attribute describes the image and is important for accessibility.

Audio

<audio controls> <source src="music.mp3" type="audio/mpeg" > </audio>

Video

<video controls width="600" > <source src="video.mp4" type="video/mp4" > </video>

HTML Lists

Three important list types.

Unordered List

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>

Ordered List

<ol> <li>Create HTML</li> <li>Add CSS</li> <li>Add JavaScript</li> </ol>

Description List

<dl> <dt>HTML</dt> <dd> HyperText Markup Language </dd> </dl>

HTML Attributes

Attributes provide additional information about elements.

What is an Attribute?

An attribute is normally written inside the opening tag.

<a href="about.html" target="_blank" > About </a>

Here href and target are attributes.

Common Attributes

  • id
  • class
  • href
  • src
  • alt
  • title
  • style
  • name
  • value
  • placeholder
  • required
  • disabled

HTML Tables

Tables display structured data.

<table> <thead> <tr> <th> Name </th> <th> Age </th> </tr> </thead> <tbody> <tr> <td> Rahul </td> <td> 20 </td> </tr> </tbody> </table>
Important: Use tables for tabular data, not for creating the overall layout of a modern webpage.

HTML5 Semantic Elements

Semantic elements describe the meaning of content.

<header>

Represents introductory content or a page/section header.

<nav>

Contains important navigation links.

<main>

Contains the primary content of the document.

<section>

Represents a thematic section of content.

<article>

Represents independent content, such as an article or blog post.

<aside>

Represents related or secondary content.

<footer>

Represents footer content for a page or section.

<figure>

Used for self-contained media or illustrations.

div vs span

Two very common generic containers.

<div>

A generic block-level container.

<div class="card"> <h2> Card Title </h2> <p> Card content </p> </div>

<span>

A generic inline container, useful for styling part of text.

<p> This is <span> important </span> text. </p>

HTML Comments

Comments help developers understand their code.

<!-- This is an HTML comment. It will not be displayed on the webpage. -->

Meta Tags & SEO

Important information for browsers and search engines.

<meta charset="UTF-8" > <meta name="viewport" content="width=device-width, initial-scale=1.0" > <meta name="description" content="My website description" > <title> My Website </title>
Remember: A descriptive title, useful description, logical headings and semantic HTML can improve usability, accessibility and search-engine understanding.

HTML Accessibility

Make websites usable by more people.

Use alt on Images

<img src="cat.jpg" alt="A cat sitting on a chair" >

Label Form Inputs

<label for="email"> Email </label> <input id="email" type="email" >

Use Semantic HTML

Prefer meaningful elements such as header, nav, main, section, article and footer where appropriate.

Keyboard Friendly

Interactive elements should be usable with a keyboard. Native buttons and links are generally preferable to clickable generic div elements.

HTML Best Practices

Habits that help you write cleaner HTML.

01 — Use Semantic Tags

Use meaningful elements instead of using div for everything.

02 — Write Clean Indentation

Proper indentation makes code easier to read and maintain.

03 — Add alt Text

Provide useful alternative text for meaningful images.

04 — Use Labels

Associate form labels with their controls.

05 — Keep CSS Separate

For larger projects, external CSS files make maintenance easier.

06 — Validate Your HTML

Check your markup for errors and invalid nesting.

Golden Rule: HTML = Structure, CSS = Design, JavaScript = Behavior.
