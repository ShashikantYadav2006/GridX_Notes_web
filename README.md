📚 GridX Notes Web

GridX Notes is a modern and responsive Cheat Notes website designed to provide easy access to programming notes and learning resources. It features a clean and interactive interface built using HTML, CSS, and JavaScript.

The website provides dedicated sections for HTML, CSS, Java, Home, Contact, and  Registration.

✨ Features
🏠 Home Section – A simple and welcoming landing page.
📖 HTML Notes – Quick reference notes for HTML.
🎨 CSS Notes – Useful CSS concepts and cheat notes.
☕ Java Notes – Programming notes and basic Java concepts.
🤖  Registration Form – Registration page with an formal theme.
📩 Contact Section – Contact page for users.
📱 Responsive Design – Clean layout for different screen sizes.
⚡ Interactive Interface – Easy navigation and user-friendly experience.
🛠️ Technologies Used
HTML5
CSS3
JavaScript
