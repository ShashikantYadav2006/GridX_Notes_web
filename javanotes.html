JavaScript Notes

Complete JavaScript notes for beginners. Learn JavaScript fundamentals, variables, operators, functions, arrays, objects, DOM, events, loops and more.

1. Introduction to JavaScript

JavaScript is a programming language used to make web pages interactive and dynamic.

HTML creates the structure, CSS creates the design, and JavaScript adds behavior and interaction.

What can JavaScript do?

  • Change HTML content
  • Change CSS styles
  • Handle button clicks
  • Validate forms
  • Create interactive menus
  • Create games and applications
  • Communicate with APIs

2. Adding JavaScript to HTML

JavaScript can be added to an HTML document using the script tag.

<script> alert("Hello World!"); </script>

External JavaScript

<script src="script.js"> </script>

3. Variables

Variables are used to store data.

let name = "Rahul"; const age = 20; var city = "Delhi";

let

Use let when the value may change.

const

Use const when the value should not be reassigned.

var

var is the older way of declaring variables. Modern JavaScript generally prefers let and const.

6. Conditional Statements

Conditional statements allow a program to make decisions.

let age = 18; if (age >= 18) { console.log("Adult"); } else { console.log("Minor"); }

else if

if (marks >= 90) { grade = "A"; } else if (marks >= 60) { grade = "B"; } else { grade = "C"; }

7. Switch Statement

let day = 2; switch (day) { case 1: console.log("Monday"); break; case 2: console.log("Tuesday"); break; default: console.log("Unknown day"); }

8. Loops

Loops are used to execute code repeatedly.

For Loop

for ( let i = 0; i < 5; i++ ) { console.log(i); }

While Loop

let i = 0; while (i < 5) { console.log(i); i++; }

For...of

const fruits = ["Apple", "Banana", "Mango"]; for ( const fruit of fruits ) { console.log(fruit); }

9. Functions

A function is a reusable block of code designed to perform a particular task.

function greet() { console.log("Hello World"); } greet();

Function Parameters

function add(a, b) { return a + b; } let result = add(10, 20);

10. Arrow Functions

Arrow functions provide a shorter syntax for writing functions.

const greet = () => { console.log("Hello"); };
const add = (a, b) => a + b;

11. Arrays

Arrays are used to store multiple values inside a single variable.

let fruits = [ "Apple", "Banana", "Mango" ]; console.log(fruits[0]);

Common Array Methods

push() pop() shift() unshift() map() filter() reduce() forEach()

12. Objects

Objects store data in key-value pairs.

const student = { name: "Alex", age: 20, course: "Web Development" }; console.log(student.name);

13. DOM - Document Object Model

The DOM represents an HTML document as a tree of objects. JavaScript can use the DOM to access and change HTML elements.

Selecting an Element

const heading = document.getElementById("title");

Changing Text

document.getElementById("title") .textContent = "Hello JavaScript";

querySelector

const box = document.querySelector(".box");

change

button.addEventListener( "click", () => { console.log( "Button clicked" ); });

15. String Methods

Method Purpose
toUpperCase() Converts text to uppercase
toLowerCase() Converts text to lowercase
trim() Removes extra spaces
includes() Checks whether text exists
slice() Extracts part of a string

16. Important Array Methods

map()

Creates a new array by transforming every element.

const numbers = [1, 2, 3]; const doubled = numbers.map(number => number * 2);

filter()

Creates a new array containing elements that pass a condition.

const numbers = [1, 2, 3, 4]; const even = numbers.filter(number => number % 2 === 0);

18. Destructuring

Destructuring allows values to be extracted easily from arrays and objects.

const person = { name: "Alex", age: 25 }; const { name, age } = person;

19. Spread Operator

The spread operator is represented by three dots and is used to expand values.

const first = [1, 2, 3]; const second = [4, 5, 6]; const combined = [ ...first, ...second ];

20. JavaScript Classes

Classes are used to create objects using a reusable structure.

class Student { constructor(name, age) { this.name = name; this.age = age; } greet() { console.log( `Hello ${this.name}` ); } }

21. JSON

JSON stands for JavaScript Object Notation. It is commonly used for storing and exchanging data between applications.

{ "name": "Alex", "age": 25, "course": "JavaScript" }

22. Asynchronous JavaScript

Asynchronous JavaScript allows tasks to run without blocking the entire program.

setTimeout

setTimeout(() => { console.log( "Hello after 2 seconds" ); }, 2000);

Promise

const promise = new Promise( (resolve, reject) => { resolve("Success"); } );

23. Fetch API

The Fetch API can be used to request data from a server or API.

fetch("https://example.com/data") .then(response => response.json()) .then(data => { console.log(data); }) .catch(error => { console.log(error); });

24. Error Handling

try...catch can be used to handle errors without stopping the entire application.

try { // Code that may cause an error } catch (error) { console.log(error); }

25. Important JavaScript Points

JavaScript is case-sensitive. For example, name and Name are different variables.
  • Use const by default when a variable does not need reassignment.
  • Use let when a value needs to change.
  • Use === for strict comparison.
  • Functions help keep code reusable.
  • Arrays store multiple values.
  • Objects store data using key-value pairs.
  • DOM allows JavaScript to interact with HTML.
  • Events allow JavaScript to respond to user actions.
